# Role-Aware Knowledge Assistant

Build a chat backend that answers from a company's internal documents, enforces who may read what inside the vector search, streams answers over WebSockets and calls operational tools in parallel.

An Inkplain practical case: a real project built step by step.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inplain-Tracks-Items/practical--role-aware-knowledge-assistant.git
cd practical--role-aware-knowledge-assistant
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
